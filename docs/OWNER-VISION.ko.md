# 소유자 비전 — HealthMes Agent의 존재 이유

> **이 문서의 지위**: 프로젝트의 최초 요구사항이자 최상위 철학이다. PLAN.md의
> 모든 설계는 이 문서에서 파생된다. **이 문서의 변경은 소유자(민성)만 결정할
> 수 있다** — 에이전트·기여자가 작업 중 이 철학과 충돌하거나 이를 바꾸는
> 요구가 생기면, 임의로 수정하지 말고 반드시 소유자에게 물어본다.
> (원문: 2026-07 초기 요구, 2026-07-30 문서화)

## 한 줄

**비서처럼 — 헬스케어 데이터 기반의 자동 스케줄 관리와 의사결정 관리 레이어.**

## 핵심 사용자 경험 ("던져놓으면 알아서")

- 나는 일정을 짜거나 뭘 고려할 필요가 없다. **주간 목표·프로젝트·할 것들·
  일정을 대충 던져놓으면**, 에이전트가 내 건강 상태·일정·인지에너지를
  고려해서 비서처럼 배치한다.
- 일정 수정·변경이 생겨도 에이전트가 알아서 반영한다.
- **내가 물어보기 전에 먼저 alert를 준다.** 시간대도 에이전트가 고려해서
  알려준다.
- 기본 상호작용 = 선제 alert 위에서 인터랙티브하게 묻고 답하기.

## 기능 두 축

1. **스케줄링** — 주간 목표 형태의 일정 관리 (배치·수정·재조정).
2. **인지에너지 피드백과 솔루션** — 스케줄 + 스트레스 지수 + 헬스케어 데이터
   + 폰/전자기기 앱 사용 시간대·빈도를 종합해 **인지에너지와 집중도를 판단**
   하고 솔루션을 준다. "이 시간대에 집중도가 떨어졌다. 왜 그렇냐?"에 답한다.

## 피드백 학습 (축적된 상관)

쓰면 쓸수록 데이터가 쌓여 **더 긴 건강 맥락**으로 판단한다:

- "어떤 상황에서 스트레스 지수가 높았는데, 그 상황·시간대는 ~~사람
  때문이었더라"
- "어떤 일을 할 때 스트레스가 낮더라 / 어떤 것을 했을 때 건강해지더라"
- 먹은 음식도 기록되어 상관에 들어간다.

## 설명가능성

사람이 판단할 때, **에이전트가 의사결정을 어떻게 했는지 트리 형태의
플로우차트**로 웹이나 알림에서 상세를 볼 수 있어야 한다.

## 데이터와 비즈니스

- **개인 데이터는 개인이 가진다. 앱은 로컬 first.**
- 데이터가 쌓이면 어딘가에 저장하고 싶어진다 — **보안이 보장되는 스토리지**가
  비즈니스 기회다. (서버는 열 수 없는 암호문만 보관; 파는 것은 데이터 접근이
  아니라 용량·내구성·무관리 편의)

## 접근성

**워치와 폰 모두** 가능해야 하고, 접근성이 좋아야 한다.

## 경계 사례 — 의료 라이트

특정 병이 있으면 워치나 폰으로 약·증상 부위 사진만 찍으면 로컬에 맥락과 함께
저장되어, 나중에 의사가 챗으로 편하게 판단하게 돕는 기능. **단, 핵심 뿌리와
결이 달라 별도 프로젝트가 될 수 있다** — 다만 이 데이터가 의사결정·스케줄링에
필요하긴 하므로 **참고할 수 있는 여지는 남긴다**. (현재 상태: 최소 구현 유지,
확장 보류 — PLAN §12)

## 단순화 원칙

필요한 기능으로 **최대한 simplify** 한다. (소유자 재확인 2026-07-27: 실데이터
없는 정교화는 오버엔지니어링 — 검증할 수 없는 정밀함을 만들지 말 것)

## 파생 원칙 (비전에서 도출되어 PLAN에 구체화된 것들)

| 원칙 | 근거가 되는 비전 항목 |
|---|---|
| propose-then-confirm — 캘린더 변경은 사용자 확인 후에만 | "비서"는 대행자이지 주인이 아니다 |
| 정직성 — 그럴싸한 거짓 금지, insufficient_data 정직 보고 | 신뢰 없는 비서는 음소거된다 |
| 숫자 계산은 결정론적 코드, LLM은 판단만 | 설명가능성 + 재현성 |
| raw-first — 원본을 먼저 보존한 뒤 데이터별 TTL로 축약, 장기 맥락은 특징·판단·결과로 유지 | "쌓일수록 더 긴 맥락" + 로컬 용량 통제 |
| 알림 위생 (예산·쿨다운·야간 금지) | 선제 alert가 소음이 되면 실패 |
| 임계값은 개인 baseline 기반 + 데이터로 자동 보정 | "개인" 비서다 |
| 로컬 first + 암호화 백업 시임 | 데이터와 비즈니스 항목 그대로 |
